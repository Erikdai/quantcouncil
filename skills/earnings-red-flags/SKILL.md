# 财报排雷清单

按顺序检查，每条给出"数据 → 结论"，引用具体报告期和数值（亿元）。数据缺失就写"无法判断"，不要猜。

## 1. 利润含金量
- 经营现金流净额 / 归母净利润：连续两期 < 0.8 为警示，< 0.5 为高风险。
- 扣非归母净利润 / 归母净利润：< 0.7 说明利润依赖非经常性损益（政府补助、资产处置、投资收益）。

## 2. 应收与存货
- 应收账款增速 > 营收增速 10 个百分点以上：可能放宽信用或提前确认收入。
- 存货增速明显快于营收、且毛利率上升：警惕存货虚增；白酒等可增值存货除外，需说明行业特性。

## 3. 资产负债表
- 存贷双高：货币资金和有息负债（短期借款 + 长期借款）同时占总资产 20% 以上，而利息收入很低。
- 商誉 / 归母权益 > 30%：并购减值风险。
- 资产负债率显著高于行业中枢，或短期借款 > 货币资金：流动性压力。
- 合同负债（预收款）大幅下降：下游需求或渠道打款意愿走弱的领先信号。

## 4. 费用与毛利
- 毛利率异常跳升且与同行背离。
- 销售费用率骤降但营收仍高增：费用可能被资本化或延后。
- 研发费用资本化比例高：利润质量打折。

## 5. 治理与外部信号（结合公告、新闻工具）
- 非标审计意见、频繁更换会计师事务所、财务总监离职。
- 控股股东高比例质押、频繁减持、大额关联交易。

## 输出格式
用表格列出：检查项 | 数据 | 结论（正常 / 警示 / 高风险）。最后给出 1–2 句总体判断及对仓位的影响。
